# 어린이집 지도 (Childcare Map)

지역별 어린이집 입소 대기 정보 비교 서비스의 초기 UI 프로토타입입니다.

## 현재 상태
- 정적 웹 프로토타입
- 지역 선택 및 지역 카드 통계 표시
- 시설 이름 검색
- 시설 유형 필터
- 대기 0명 필터
- 모바일 반응형 레이아웃

## 주의
현재 표시되는 지역·시설·대기 수치는 **모두 가상의 데모 데이터**입니다. 실제 어린이집 현황, 시설 주소, 대기 인원과 무관합니다. 공공데이터 API 연동 전 UI 테스트 용도로만 사용하세요.

## 실행
파일을 내려받은 뒤 `index.html`을 브라우저에서 열면 됩니다. 별도 빌드 과정이 없습니다.

## 다음 개발 단계
1. 공식 데이터 API 조사 및 사용·재배포 조건 확인
2. 실제 필드 및 지역코드 검증
3. 데이터 수집·검증 파이프라인
4. 저장소 및 스냅샷 DB
5. 읍·면·동 단위 집계
6. 지도/지역 탐색 및 시설 상세
7. 실제 데이터 연결, 자동 업데이트, 테스트
8. SEO 및 배포 준비

## 원칙
- 무료 서비스로 시작
- 초기 광고 없음
- Lock-in First: 지역 저장, 비교, 변화 추적, 데이터 히스토리를 통해 재방문 가치 강화
- 데이터 출처와 갱신일 명확히 표시
- 신고/위반 이력 기능은 전체 기능 완료 후 마지막에 별도 검토
- 사용자 승인 없이 배포하지 않음
